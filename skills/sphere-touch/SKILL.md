# Sphere touch

1. `keep_in_touch_due` for who's past due; add `find_contacts` with stage Past client (or the tag the agent names) if they want more.
2. Pick at most 10 people for today, oldest touch first. Show the list and ask before drafting.
3. Draft one message per person (`draft_text` or `draft_email`) in the agent's voice. Make each one personal from what KONAH shows (their home, the last note), one line of value (a local event, a quick market note in general terms), and a soft ask only when it fits. No stats or prices you weren't given.
4. If someone should be on a regular cadence, offer `set_keep_in_touch` (A every 30 days, B 90, C 180).
5. Tell the agent the drafts are waiting in KONAH → Ask KONAH → Ready to send.
